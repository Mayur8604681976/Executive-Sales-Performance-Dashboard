# Executive Sales Performance Dashboard | Power BI

## Project Overview

The **Executive Sales Performance Dashboard** is an interactive business intelligence project developed using Microsoft Power BI. It provides a consolidated view of sales performance through key performance indicators (KPIs), charts, and interactive filters.

The dashboard helps users explore revenue, gross profit, gross margin, quantity sold, and order volume while comparing performance across countries, product categories, sales channels, and months.

## Objectives

- Monitor key sales performance indicators.
- Analyze monthly revenue and gross profit trends.
- Identify the top 5 and bottom 5 countries by revenue.
- Compare revenue contributions from different sales channels.
- Understand revenue distribution across product categories.
- Enable interactive analysis using slicers.

## Key Performance Indicators (KPIs)

The dashboard includes the following KPIs:

- **Total Revenue:** Overall revenue generated.
- **Total Gross Profit:** Gross profit earned from sales.
- **Gross Margin:** Gross profit as a percentage of revenue.
- **Total Quantity:** Total quantity of products sold.
- **Total Orders:** Total number of orders.

## Dashboard Features

### 1. Monthly Sales Trend Analysis
A line chart compares total revenue and total gross profit across months to help explore sales trends over time.

### 2. Top 5 Countries by Revenue
A bar chart identifies the five highest-performing countries based on revenue.

### 3. Bottom 5 Countries by Revenue
A bar chart highlights the five countries with the lowest revenue among the countries included in the analysis.

### 4. Sales Channel Revenue Comparison
A pie chart compares revenue contributions from different sales channels, including Online Store, Corporate, Retail Partners, and Marketplace.

### 5. Product Category Revenue Analysis
A doughnut chart visualizes revenue distribution across product categories.

### 6. Interactive Slicers
Users can filter the dashboard by:
- Quarter
- Month
- Product Category
- Country

These filters allow users to explore different segments of the sales data.

## How to Use This Project

1. Download or clone this repository.
2. Locate the Power BI `.pbix` file.
3. Install Microsoft Power BI Desktop if it is not already installed.
4. Open the `.pbix` file in Power BI Desktop.
5. Interact with the slicers to filter the dashboard by quarter, month, product category, or country.

If the original data source is external, you may need to update the data source path or credentials before refreshing the report.
